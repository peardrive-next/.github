# 🍐 PearDrive

**PearDrive** is a **peer-to-peer (P2P) file sharing and streaming platform** built on the **[Pear Network](https://github.com/holepunchto/pear)**.<br>
It enables decentralized file distribution and streaming without reliance on centralized infrastructure.

<br>

## Organization Repository Guide

- **📂 `documents`**  
  Contains documentation, technical concepts, and work-in-progress materials in Markdown format.<br>
  > Includes architectural references, design notes, and implementation outlines.

<br>

- **📂 `prototype-core`**  
  Core application layer for implementing file sharing and streaming on the **Pear Network**.<br>
  > 🛠️ *Status:* Work in Progress

<br>

- **📂 `prototype-monitor`**  
  Monitoring and diagnostics interface for the PearDrive network.<br>
  Provides command-line and web-based tools for real-time network observation.<br>
  > 🛠️ *Status:* Work in Progress

<br>

- **📂 `prototype-desktop`**  
  Desktop client for PearDrive, developed using **Electron**.<br>
  Supports peer-to-peer file sharing and streaming from a desktop environment.<br>
  > 🛠️ *Status:* Work in Progress
